# itp-simulator

Интерактивный тренажер-симулятор **индивидуального теплового пункта (ИТП)** 9-этажного жилого дома
в браузере. Независимая схема присоединения отопления через пластинчатый теплообменник (ПТО),
расчетный режим при T<sub>нар</sub> = −10 °C.

## Запуск

Сборка не нужна — откройте `index.html` двойным кликом. Tailwind CSS подключается через CDN,
поэтому для красивого оформления нужен интернет; логика и схема работают и без него.

## Файлы

| Файл | Назначение |
|---|---|
| `physics.js` | Детерминированное физическое ядро (`window.ITPPhysics`): гидравлика первичного контура по Kv, давление внутреннего контура (подпитка, дренаж, насос, предохранительный клапан), теплообмен в ПТО с тепловой инерцией (явный Эйлер), диагностика аварий. Без случайных чисел. |
| `index.html` | SCADA-интерфейс: SVG-мнемосхема (`viewBox 0 0 1000 520`) с разрезом ПТО (чередующиеся каналы сети и дома, противоток), пульт арматуры, табло аварий, тренд, журнал, карточки «Зачем нужен этот элемент?». |
| `app.js` | Главный цикл (`setInterval` 100 мс, `dt = 0.1 с`, ускорение ×2/×5, пауза), связь пульта с ядром, анимация потоков (`stroke-dasharray`, скорость ∝ расходу), цвет труб по температуре, показания приборов. |

## Органы управления

- **V1 / V2** — задвижки подачи и обратки теплосети (Kvs 80). Управляются кнопкой «Открыть / Закрыть»: затвор за 8 с идет
  к крайнему положению, остановить его посередине нельзя (команду можно развернуть на ходу). Промежуточные положения
  существуют только во время хода — так же, как на реальной запорной арматуре.
- **Грязевик** — ползунок засорения 0…90 % (Kv 60 → 6).
- **КЗР** — регулирующий клапан (Kvs 16), кнопки ±1 % для точной подстройки.
- **Подпитка** — из сетевой обратки (отбор до V2, через обратный клапан) во всас насоса.
- **Насос** (перепад 1.8 бар) и **дренаж** (переключатель: открыт/закрыт).
- **«Сбросить в штатный режим»**: V1 = V2 = 100 %, КЗР = 48 %, насос ВКЛ, P21 = 3.5 бар, режим сразу установившийся.

## Диагностика

Аварии 🔴: опрессовка ПТО подающим давлением, кавитация насоса, подача без циркуляции,
срабатывание предохранительного клапана. Предупреждения 🟡: T2 > 55 °C (штраф теплосети),
засорение грязевика (ΔP > 0.6 бар), недотоп/перетоп (T11 вне 70…80 °C).
🟢 НОРМА — когда замечаний нет. Все события пишутся в журнал с временем симуляции.

## Отступления от исходного ТЗ и почему

Исходный набор чисел физически несовместим: при T11 = 75 °C и остывании в доме на 19 °C
обратка из дома T21 = 56 °C, а в противоточном ПТО сетевая вода не может остыть ниже входящей
холодной воды — значит, T2 ≤ 55 °C недостижимо ни при каком положении КЗР (нужна эффективность ПТО > 100 %).
Тогда «штатный режим» вечно горел бы штрафом теплосети.

Чтобы штатный режим (КЗР = 48 %) действительно давал зеленый статус, изменены два параметра
(константы в начале `physics.js`):

| Параметр | ТЗ | В модели |
|---|---|---|
| Остывание воды в доме T11 − T21 | 19 °C | **30 °C** (график 75/45) |
| Расход в системе отопления G2 | 22 т/ч | **14 т/ч** |

Результат в штатном режиме: G1 ≈ 10.2 т/ч, Q ≈ 488 кВт, T11 ≈ 74.9 °C, T21 ≈ 44.9 °C, T2 ≈ 53.9 °C.
Рабочий коридор КЗР без замечаний — примерно 44…49 %.

Прочие уточнения:
- Без циркуляции (насос выключен или в кавитации) вода в стояках остывает к 20 °C с τ = 60 с —
  иначе «дом остывает» из аварийного сообщения не было бы видно.
- Перепад на грязевике считается по двум манометрам непосредственно до и после него
  (при полностью открытой V1 это совпадает с P1 − P<sub>после гр</sub>), чтобы закрытая V1 не давала ложного «засора».
- Предохранительный клапан работает с гистерезисом (открытие > 6.0 бар, посадка < 5.9 бар) и
  реально сбрасывает давление контура. Полностью открытая подпитка поднимает P21 к 4.5 бар → P11 = 6.3 бар → срабатывает ПК.
  При закрытой V2 подпитка берет уже 6.5 бар — это сценарий «гидроудара».
